# Design.md - ROMB Drums booking site

Locked бренд-ДНК (Blueprint 00b, одобрено Марией 2026-08-13). Источник цвета/типографики для ВСЕХ экранов - сюда, не выдумывать заново на Фазе 4/5.

## Настроение
Тёмный, дерзкий, роскошный, энергичный, чувственный. НЕ сдержанно-люксовый отельный тон, НЕ дефолтный AI-минимализм.

## Палитра (locked)

```css
:root {
  --bg:            #14100D;  /* тёплый почти-чёрный, не нейтральный чёрный */
  --surface:       #1C1613;  /* карточки/панели */
  --ink:           #F5EFE8;  /* тёплый белый текст */
  --ink-muted:     #B8A99A;
  --accent-wine:        #8C1D2B;  /* глубокий винно-красный, primary */
  --accent-wine-hover:  #A52638;
  --accent-gold:        #C89B4A;  /* тёплое золото/латунь, secondary */
  --accent-gold-hover:  #D9AF63;
  --border: rgba(200,155,74,0.18); /* тонкая золотая обводка */
}
```

Контраст WCAG: `--ink` на `--bg` и `--surface` >4.5:1 (тёплый белый на почти-чёрном - высокий контраст). `--accent-gold` на `--bg` для крупного текста/иконок ok, для мелкого текста - не полагаться, использовать `--ink`.

## Типографика (locked, Фаза 4, 2026-08-13)

```css
--font-display: 'Fraunces', serif; /* заголовки, крупный кегль, wght 900, italic для акцентов */
--font-body:    'Work Sans', sans-serif; /* текст, wght 400/500 */
```

Fraunces - высококонтрастный serif с мягкими "чувственными" изгибами и тяжёлым весом на крупном кегле: даёт "дерзкий/роскошный" без дефолтного AI-минимализма (не Inter/Manrope в заголовках). Курсив Fraunces - для eyebrow-лейблов и акцентных слов внутри заголовков. Work Sans - нейтральный читаемый гротеск для тела текста, не спорит с display-шрифтом. `font-display: swap` на обоих (Google Fonts). Источник решения - `04-visual.md`, жанровая планка ниже.

## Референсы жанра (Фаза 2, 2026-08-13)

Живой EPK-класса-один-акт в нише почти не индексируется отдельно (рынок работает через агентские каталоги), поэтому планка собрана из двух пулов:
- **Пул A (агентства-каталоги того же типа продукта - live percussion/drummer booking):** live-entertainment.co.uk/hire/drummers-and-percussion, contrabandevents.com/drummers, scarlettentertainment.com/.../drumming-and-percussion, tailored-entertainment.com/djs/djs-with-percussion - структура: hero-обещание → соцдоказательство/логотипы площадок → форматы акта → CTA на заявку, без публичной цены.
- **Пул B (кросс-ниша, тёмный люкс-visual + артист-EPK форма):** dleeventgroup.com (fetched: тёмный фон + gold/diamond акценты, структура hero→proof-логотипы→дифференциаторы→кейсы→testimonials→CTA "Check Availability", тон "decades from now people are still raving") и soul-trane.webflow.io (fetched: тёмная сцена, крупный display-заголовок с именем артиста, слоистая imagery, модульные секции).
- **Синтез для ROMB Drums:** взять у Пула A порядок "proof→формат акта→CTA-заявка" (это buyer journey ивент-организатора), у Пула B - визуальный язык (тёмный фон, крупный характерный display-шрифт, слоистое видео вместо статичных фото) и прямой обращённый-к-первому-лицу тон вместо агентского "hire a performer".
